  -- WEDDING API -- 

  Projeto para gerenciador de casamento.

  1 - Registrar o evento com =  Data do evento, Nome dos noivos, Data para limite de confirmação e numero de convidados para cada noivo.

  2 - Registrar um grupo de convidados = Nome desse grupo, de qual lado esse grupo é (noivo ou noiva) e associar esse grupo ao casamento.

  3 - Registrar um convidado = Nome do convidado, status da presença dele, o grupo do qual ele pertence e se ele será responsável do grupo que ele está.



  Para melhor entendimento sobre o que seria um grupo, um grupo pode ser considerado como uma familia.
  para melhor gerenciamento, se adiciona um grupo e convidados a esse grupo pois assim se tem um melhor entendimento de quem é esse convidado.
